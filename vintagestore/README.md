# Vintage Store

An Expo/React Native vintage sneakers and streetwear store with local SQLite cart and checkout data.

## Get started

Install dependencies:

```bash
npm install
```

Start the app:

```bash
npm start
```

Start a platform-specific build:

```bash
npm run android
npm run ios
npm run web
```

## Validation

```bash
npm run lint
npx tsc --noEmit
npx expo-doctor
```
